01 / THE QUESTION

What does the footage actually support?

A broadcast combines live action, replays, camera movement and occlusion. We investigated which penalty features could be observed, which changes improved the outputs, and whether a reproducible pipeline transferred to another match.

The project separates output coverage from agreement with reference labels. An answer can be available and still be wrong; a missing answer can reflect insufficient evidence. Both the outputs and the reasons for abstaining are retained.

02 / THE METHODS

Rules, visual evidence and small learned models.

New methods were compared with retained controls. Increasing output coverage alone was not enough to justify replacing a default.

A / EVENT & BALL

Find the event before measuring it.

YOLO11 detections and temporal rules locate the ball and bracket contact. The pipeline retains frame timestamps and tracks ball observations. Scoreboard changes and ball-trajectory evidence are combined for outcome, with unknown retained on insufficient or conflicting evidence.

B / POSE & LANDINGS

Check which foot, then test support.

Pose estimation on the original and mirrored crop checks left/right consistency. Heel and toe motion provide landing candidates after camera-motion correction. Kicking-foot and landing heads learn from these frozen features rather than training a new end-to-end vision network.

C / CAMERA & GEOMETRY

Separate player motion from the camera.

Shi–Tomasi corners, Lucas–Kanade optical flow and RANSAC estimate background motion. Pitch and goal references can support a ground-plane homography. Sparse projected foot points remain hypotheses; they do not establish a validated metric trajectory or dive height.

D / LEARNING & CONTROLS

Keep improvements that survive comparison.

Regularised logistic regression and histogram gradient-boosted trees operate on frozen features. A learned outcome experiment using frozen ResNet18 features failed to transfer and did not replace the scoreboard rule. Detector augmentation also failed to improve the selected controls.

05 / THE SEPARATE 2022 CHECK

Execution transferred. Accuracy remained limited.

The frozen pipeline was run on eight penalties from the Argentina–France final without reference labels or manual input during inference. The result is kept separate from the 39 development kicks.

Completion is not generalisation.

All eight clips ran end to end, but three kicking-foot answers were correct when unknowns were counted as wrong. Outcome and goalkeeper height remained unknown throughout this check.

The report describes a fixed inference run with no model adjustments using these results. Eight clips from one match provide only a limited transfer check.

A reliable estimate of performance on new broadcasts still needs more diverse, independently reviewed footage.

Team implementation and dependencies

The course team repository contains the shared implementation. Ultralytics, OpenCV, MediaPipe, scikit-learn and PyTorch supply model and numerical building blocks. The team connects them through event rules, feature extraction, model comparisons and review outputs.

Reproducibility boundaries

Saved outputs retain source hashes and frame timestamps; analysis and review pages can be regenerated from the retained data. Source broadcast videos, model weights and private local paths are not added to this portfolio. A separate-machine run demonstrates execution, not independent measurement accuracy.

07 / LIMITATIONS

What remains unresolved.

01

Four camera-angle timings

The required behind-kicker, kicker-right 45-degree, slow-motion kicker close-up and slow-motion behind-goalkeeper intervals remain unresolved. Camera-motion correction is a different task.

02

Height and final position

Strict dive height and final ball position lack verified reference geometry. Sparse ground projections cannot substitute for calibrated physical measurements.

03

Reference quality

One reviewer supplied development labels. There is no inter-reviewer agreement estimate, and only three development kicks are left-footed. Label quality and class imbalance limit interpretation.

04

Transfer beyond development

Eight clips from one additional match are too few for a precise generalisation estimate. More diverse footage and independently reviewed labels are needed, particularly for landings, height and short-clip outcomes.
